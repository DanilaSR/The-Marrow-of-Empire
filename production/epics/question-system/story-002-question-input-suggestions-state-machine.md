## Implementation Notes

*Derived from GDD CR-1 (Input Methods), CR-3 (Question Context), CR-4 (Topic Suggestion Generation), States and Transitions:*

### State Machine

```
Idle → Active → Processing → Waiting → Response → Active (follow-up)
                                                   → Idle (conversation close)
```

| State | Meaning | Input Behaviour |
|-------|---------|----------------|
| `Idle` | No conversation active | Input hidden |
| `Active` | Conversation with NPC active | Text input visible, suggestions shown, input enabled |
| `Processing` | Question submitted, topic matching in progress | Input disabled, suggestions hidden |
| `Waiting` | Facts routed to AI Dialogue Engine, waiting for LLM | Input disabled, "thinking" indicator active |
| `Response` | NPC response displayed | Input re-enabled for follow-up, suggestions refreshed |

### Question Input (CR-1)

```go
type QuestionInput struct {
    state       ConversationState
    currentNPC  GameEntityID
    history     []QuestionRecord  // last 3 questions (any NPC)
    inputText   string            // current text field content
    suggestions []TopicSuggestion // current suggestion chips
}

type QuestionRecord struct {
    Question   string
    NPC        GameEntityID
    MatchResult MatchResult  // from Story 001 topic matcher
}
```

**Free-text input**: Player types into a text field. Natural language. Submit on Enter. Input length capped at 500 characters (enforced by the Question System before routing to AI Dialogue Engine — see GDD CR-3 step 10 for AI Dialogue).

**Empty input validation**: On submit, if `strings.TrimSpace(inputText) == ""`, reject with `InputRejectedEvent{Reason: "empty"}`. The Dialogue UI responds with a shake animation (3 horizontal oscillations, 150ms).

### Topic Suggestion Generation (CR-4)

Generated fresh each time conversation opens or after a response:

```go
type TopicSuggestion struct {
    Text     string // natural question text, e.g. "What do you know about smithing?"
    Source   SuggestionSource
    Priority int    // lower = higher priority
    Domain   string // the domain this maps to (for chip styling)
}

type SuggestionSource int
const (
    SuggestionFromThread SuggestionSource = iota  // thread-based (highest priority)
    SuggestionFromEntity                           // entity-based
    SuggestionFromDomain                           // domain-based (lowest priority)
)
```

1. **Domain-based** (always present): One suggestion per NPC domain, phrased as a natural question. Domain label → question template, e.g. `craft_metallurgy` → "What do you know about smithing?"

2. **Thread-based** (if applicable): For each active investigation thread intersecting with this NPC's knowledge (thread references entity the NPC has facts about): "Ask about the old mine."

3. **Entity-based** (if applicable): For recently mentioned entities in conversation history: "Ask about Captain Veren."

4. **Capped at 6 suggestions**. Priority: thread-based > entity-based > domain-based. Within each tier, order by recency (threads) or authored domain order.

### Suggestion Chip Interaction

Clicking a chip → the suggestion `Text` fills the text input field. The player can edit before submitting. This is a data event (`SuggestionSelectedEvent`), not a direct UI manipulation — the Dialogue UI reads the event and updates the input field.

### Conversation History (CR-3)

The system tracks the last 3 questions (any NPC, not just current). History is used by:
- Story 001 topic matcher: resolves "it"/"that"/"they" against prior topic context
- Topic suggestions: entity-based suggestions from recently mentioned entities

### Events Emitted

| Event | Trigger | Consumer |
|-------|---------|----------|
| `ConversationStarted` | Player opens conversation with NPC | Dialogue UI, AI Dialogue Engine |
| `QuestionSubmitted` | Player submits non-empty question | Story 001 topic matcher |
| `InputRejected` | Empty/whitespace-only submission | Dialogue UI (shake animation) |
| `TopicMatched` | Story 001 matcher completes | AI Dialogue Engine (fact routing) |
| `SuggestionsRefreshed` | New suggestions generated | Dialogue UI (chip display) |
| `SuggestionSelected` | Player clicks a suggestion chip | Dialogue UI (fill input) |
| `ConversationClosed` | Player ends conversation | Dialogue UI, AI Dialogue Engine |
