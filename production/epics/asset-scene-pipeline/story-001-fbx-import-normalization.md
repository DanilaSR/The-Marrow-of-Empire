## Acceptance Criteria

- [ ] GIVEN a KitBash3D FBX asset, WHEN ImportAsset runs, THEN the mesh is converted to Kaiju native format with correct vertex data
- [ ] GIVEN KitBash3D assets from both packs, WHEN scale normalization runs, THEN both packs normalize to 1 unit = 1 meter (2-unit door reference validates)
- [ ] GIVEN a KitBash3D asset with Z-up orientation, WHEN rotation normalization runs, THEN the asset converts to Y-up for Kaiju
- [ ] GIVEN BLEND source files, WHEN the pipeline runs, THEN they are exported to FBX first (manual or headless Blender)
- [ ] GIVEN a non-power-of-two texture, WHEN imported, THEN it is padded to next PoT with warning logged

## Implementation Notes

From ADR-0004: Source directory is read-only. All modifications happen in staging. FBX/OBJ accepted; BLEND exported to FBX first. Scale reference object: human-height door at 2 world units. PoT padding for textures.
