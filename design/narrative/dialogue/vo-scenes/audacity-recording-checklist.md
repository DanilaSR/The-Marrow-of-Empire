# Чек-лист записи в Audacity

**Пак:** «Холод старой леди» — 3 сцены, 72 реплики, ~6 минут
**Порядок записи:** Vek (S01 → S03) → Tomas (S01 → S02) → Mira (S02 → S03)
**Реплик по персонажам:** Vek 23 · Tomas 24 · Mira 25 · ★ 8 реплик
**Формат:** 48 кГц / 24 бит / моно WAV, пики около −12 dBFS

---

## 0. За 15 минут до записи

- [ ] Комната: закрыть окна, выключить вентилятор/кондиционер, холодильник — если слышно
- [ ] Телефон в авиарежим, уведомления на компьютере выключены
- [ ] Микрофон: 15–20 см, чуть сбоку от оси, поп-фильтр на месте
- [ ] Закрытые наушники подключены — без них будет эхо в записи
- [ ] Вода комнатной температуры рядом; не горячий чай и не кофе перед записью
- [ ] Текст открыт в телепромптере: `teleprompter.html`
- [ ] Манифест `recording-manifest.csv` открыт для сверки имён

## 1. Настройка Audacity

- [ ] Подключить микрофон и убедиться, что система его видит
  (`pavucontrol` → Input Devices, или `wpctl status` при PipeWire)
- [ ] **Audio Setup → Audio Settings:**
  - **Host:** PulseAudio (при PipeWire работает через pipewire-pulse) или ALSA
  - **Recording Device:** ваш микрофон
  - **Recording Channels:** **1 (Mono)**
- [ ] **Audio Setup → Project Sample Rate:** **48000**
- [ ] Если Audacity установлен через Flatpak — разрешить доступ к микрофону в настройках Flatpak/портала
- [ ] Открыть индикатор записи: **Click to Start Monitoring** и проверить шкалу

> Если микрофон не виден: смените Host (ALSA ↔ PulseAudio) и перезапустите Audacity. В ALSA устройство часто называется `default` или `hw:1,0`.

## 2. Проверка уровня (2 минуты)

- [ ] Говорите самой громкой репликой пака — Vek, «No.» (S03-VEK-014)
- [ ] Пики около **−12 dBFS**, не выше −6; красный индикатор клиппинга не загорается
- [ ] Если тихо/громко — регулируйте усиление микрофона или интерфейса, **не** ползунок в Audacity
- [ ] Запишите **10 секунд тишины в комнате** — это `room-tone` для дальнейшей обработки
- [ ] Прослушайте тест: нет ли гула, щелчков, треска, эха

## 3. Проект и папки

- [ ] Создайте папку сессии, например `~/vo/marrow/2026-11-04/`
- [ ] Внутри — папки `vek/`, `tomas/`, `mira/`, `export/`, `room-tone/`
- [ ] **File → Save Project As** → `~/vo/marrow/2026-11-04/marrow-vo.aup3`
- [ ] Сохраняйте проект после каждого пасса (**Ctrl+S**)

## 4. Запись пасса

Для каждого персонажа — отдельный проход, чтобы голос не «плыл».

- [ ] **R** — начать запись
- [ ] Слейт в начале (по желанию): «Scene one, Vek, take one» — потом вырежете
- [ ] Перед каждой репликой — **Ctrl+B**, введите VO ID (например `S01-VEK-001`), Enter
- [ ] Говорите реплику; после неё пауза 0.5–1 с — это удобно резать
- [ ] Дубли: запишите ещё раз и поставьте метку `S01-VEK-001_take2`, `_take3`
- [ ] **Space** — остановить запись
- [ ] Прослушайте последнюю реплику; если брак — перепишите сразу
- [ ] **Ctrl+S** — сохранить проект

**Важно:** метки (labels) — это не украшение. Именно по ним `Export Multiple` нарежет и назовёт файлы.

## 5. Порядок проходов

| Проход | Сцены | Что помнить |
|---|---|---|
| **Vek** | S01 → S03 | Один голос на оба прохода; арка от «не верю» до «иду проверять» |
| **Tomas** | S01 → S02 | В S01 он ещё защищается; в S02 не спал — стыд сильнее |
| **Mira** | S02 → S03 | В S02 восторг скрывается хуже, в S03 — максимально осторожна |

- [ ] Vek: 23 реплики
- [ ] Tomas: 24 реплики
- [ ] Mira: 25 реплик
- [ ] Все 8 ★-реплик записаны в 2–3 дублях

> Если голос устал — не тяните. Лучше 3 коротких сессии, чем одна двухчасовая с «севшим» голосом.

## 6. Отбор киперов

- [ ] Прослушайте каждый дубль, выберите лучший
- [ ] Запишите номер кипера в `recording-manifest.csv`, колонка `дубль_кипер` (`1`, `2`, `3`)
- [ ] Лишние дубли можно оставить как альтернативы — суффикс `_takeN` в имени
- [ ] Если дубль не нужен — удалите его метку, чтобы он не попал в экспорт

## 7. Экспорт

- [ ] **File → Export → Export Multiple** (в новых версиях — Export → Multiple Files)
- [ ] **Split files based on:** Labels
- [ ] **Name files:** Using Label/Track Name
- [ ] **Format:** WAV (Microsoft)
- [ ] **Encoding:** Signed 24-bit PCM
- [ ] **Folder:** `~/vo/marrow/2026-11-04/export/`
- [ ] Нажать Export; проверить, что предупреждений о перезаписи нет

> Если `Export Multiple` недоступен: выделите регион между двумя метками → **Ctrl+Shift+E** (Export Selected Audio), имя файла вручную по VO ID.

## 8. Проверка результата

- [ ] Всего файлов: **72** (Vek 23 + Tomas 24 + Mira 25), без учёта `_takeN`
- [ ] Имена совпадают с колонкой `файл` в манифесте
- [ ] Нет пустых файлов и обрезанных реплик
- [ ] Выборочно проверить формат: 48 кГц, 24 бит, моно

Сверка имён с манифестом (Linux):

```bash
MANIFEST=~/BG2/design/narrative/dialogue/vo-scenes/recording-manifest.csv
EXPORT=~/vo/marrow/2026-11-04/export

grep -v '^vo_id,' "$MANIFEST" | cut -d, -f5 | sort > /tmp/expected.txt
ls "$EXPORT"/*.wav | xargs -n1 basename | grep -v '_take[0-9]' | sort > /tmp/actual.txt
diff /tmp/expected.txt /tmp/actual.txt && echo "OK — все 72 файла на месте"
```

Проверка параметров одного файла:

```bash
ffprobe -v error -show_entries stream=sample_rate,channels,bits_per_raw_sample \
  -of default=nw=1 ~/vo/marrow/2026-11-04/export/S01-VEK-001.wav
```

Ожидаемо: `sample_rate=48000`, `channels=1`, `bits_per_raw_sample=24`.

## 9. Бэкап

- [ ] Скопировать папку сессии (проект `.aup3` + экспорт) на второй диск или в облако
- [ ] Не перезаписывать «мастер»-файлы обработкой; все эффекты — только на копиях
- [ ] Сохранить `room-tone.wav` — он понадобится для шумоподавления

## 10. Типичные проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Микрофон не виден | Не тот Host или Flatpak без доступа | Сменить Host ALSA ↔ PulseAudio; проверить разрешения Flatpak |
| Эхо в наушниках/записи | Звук играет из колонок | Только наушники; отключить мониторинг из колонок |
| Клиппинг (красный) | Слишком высокое усиление | Уменьшить gain на микрофоне/интерфейсе, не в Audacity |
| Тихий ровный гул | Вентилятор, холодильник, блок питания | Выключить источник; не спасать эквалайзером |
| Файлы не нарезались | Нет меток или не выбран Labels | Проверить наличие меток: Ctrl+B перед каждой репликой |
| Имена файлов неверные | Опечатка в метке | Исправить метку двойным кликом, экспортировать заново |
| Реплики «слиплись» | Нет паузы между дублями | Пауза 0.5–1 с; при необходимости раздвинуть вручную |
| Щелчки от клавиатуры | Микрофон ловит стол | Микрофон на стойке, клавиатура подальше или тише |

## 11. Быстрый чек-лист (одним экраном)

1. 48 кГц, моно, пики −12 dBFS, 10 с room tone.
2. R — запись, Ctrl+B — метка с VO ID перед каждой репликой.
3. Пауза 0.5–1 с между репликами; дубли — `_takeN`.
4. Space — стоп, Ctrl+S — сохранить.
5. Проходы: Vek → Tomas → Mira.
6. Выбрать киперы → заполнить `дубль_кипер`.
7. Export Multiple по меткам → WAV 24-bit.
8. Сверить 72 имени с `recording-manifest.csv`.
9. Бэкап проекта и экспорта.

---

**Ориентировочное время:** 2–2.5 часа на всё, включая настройку и отбор дублей.
