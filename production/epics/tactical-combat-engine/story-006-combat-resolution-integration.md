**ADR Decision Summary**: Resolution emits CombatEnded via EventBus, distributes XP, resumes clock, restores camera.

**Engine**: Kaiju 26.07.29.1-nightly | **Risk**: HIGH

## Acceptance Criteria

- [ ] GIVEN all enemies dead, WHEN resolution runs, THEN CombatEnded{result=VICTORY, xp} emitted
- [ ] GIVEN all party dead, WHEN resolution runs, THEN CombatEnded{result=DEFEAT} emitted
- [ ] GIVEN combat ends, WHEN resolution completes, THEN game clock resumes
- [ ] GIVEN victory, WHEN XP distributed, THEN each survivor gets share via AwardXP
- [ ] GIVEN resolution, WHEN events emit, THEN clock resumes and camera returns to Exploration

## Implementation Notes

From ADR-0009: Single-frame resolution: determine result, calculate XP (sum enemy XP / survivors), emit CombatEnded event, resume clock, camera → Exploration. All via EventBus — no direct cross-system calls.

- Post-combat dialogue triggers
