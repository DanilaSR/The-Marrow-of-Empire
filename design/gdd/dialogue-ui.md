# Dialogue UI

> **Status**: In Design
> **Author**: Claude + user
> **Last Updated**: 2026-08-09
> **Implements Pillar**: Pillar 1 (Every Voice Holds a Piece — the UI where voices are heard)

## Summary

The Dialogue UI is the conversation interface — where the player asks questions,
sees NPC responses, and navigates the conversation. Text input with topic
suggestions, NPC portrait with trust indicator, typewriter text display, and
the "thinking" animation during LLM generation. Parchment-themed per the art
bible's UI palette.

> **Quick reference** — Layer: `Presentation` · Priority: `MVP` · Key deps: `Question System`, `AI Dialogue Engine`

## Overview

The Dialogue UI is where conversation happens. It displays the NPC's portrait
and name, the conversation history (scrolling log of questions and responses),
a text input field with topic suggestion chips, and a trust indicator. During
LLM generation, it shows a "thinking" animation. Responses appear with a
typewriter effect.

The UI slides up from the bottom of the screen when conversation starts and
hides when conversation ends. It occupies the lower third of the screen,
leaving the game world visible above it.

## Detailed Design

**Layout:**
- **Top**: NPC name + trust indicator (amber border glow at trust 1+, full glow at 3). "End Conversation" button (X).
- **Center**: Scrolling conversation log. Player questions in amber-left. NPC responses in parchment-right. Most recent at bottom, auto-scrolls.
- **Bottom**: Text input field + topic suggestion chips (max 6, scrollable horizontally). Submit button (Enter key also submits).

**States:** `Hidden` (no conversation) → `Active` (input enabled) → `Processing` (question submitted, input disabled, thinking animation) → `Response` (text appearing with typewriter effect, input re-enabled on completion).

**Thinking animation**: Three dots pulse sequentially (0.5s per dot) next to the NPC portrait. Text "..." in the response area.

**Typewriter effect**: Response text appears character by character at 20 chars/sec. Player can click to skip and show full text instantly.

**Topic suggestions**: Generated by Question System. Displayed as clickable chips below the text input. Clicking fills the input. Updates after each NPC response.

## Visual/Audio Requirements

| Event | Visual | Audio |
|-------|--------|-------|
| Conversation start | UI slides up (300ms); NPC portrait appears | Parchment unfurl |
| Question submitted | Input pulses amber; chips hide | Quill scratch |
| Thinking | Three-dot pulse animation | None |
| Response typing | Typewriter text reveal | Soft tick per character (very subtle) |
| Trust increase | Portrait border amber pulse (500ms) | Soft chime |
| Conversation end | UI slides down (200ms) | Parchment roll |

## Acceptance Criteria

- **GIVEN** conversation with an NPC, **WHEN** the player types a question and submits, **THEN** the input is disabled, the thinking animation plays, and the response appears with typewriter effect on completion.
- **GIVEN** LLM degraded mode, **WHEN** a response is generated, **THEN** facts display as plain text without typewriter effect and the degraded indicator shows.
- **GIVEN** trust level change during conversation, **WHEN** trust increases, **THEN** the portrait border pulses amber.
